# Literary catalog design

Intent: turn the existing small, source-backed book finder into a literary library rather than a generic card dashboard. Design choices were delegated.

Direction: paper and forest ink, expressive system serif typography, original non-cover book-spine graphics, a shelf illustration and horizontal catalog entries beside a compact faceted-search rail. The existing publication metadata, language distinction, warnings and subjective tag caveats remain intact. Actual covers and ratings were rejected because rights and reader-review evidence are absent.

Plan: snapshot remote files/head; fail a new presentation-hook check; add versioned local CSS plus decorative original SVG; preserve active JS, tags, search datasets and source links; run static preservation and DOM filter tests; expected-head publication; verify workflow and public files; desktop/mobile visual QA. No external assets, dependencies or new factual claims.
